# Project Statement

## Project Title

Random Password Generator – SecurePass

## Problem Statement

Weak and easily predictable passwords can create security problems.
Many users use simple passwords that are easy to guess.

SecurePass is designed to generate random passwords based on the
user's selected password length and analyze the strength of the
generated password.

## Objective

The main objectives of SecurePass are:

1. To generate random passwords.
2. To analyze password strength.
3. To provide useful password suggestions.
4. To maintain a history of generated passwords.
5. To demonstrate Python programming concepts through a practical project.

## Scope

The project focuses on password generation and basic password
strength analysis. It is developed as an educational project
using Python.

## Technologies Used

- Python
- VS Code
- Python Standard Library
