             ## Flow Description

1. The program starts and displays the SecurePass interface.

2. The user selects an operation from the available options.

3. If the user chooses password generation, the required password
   length is entered.

4. The entered input is checked to make sure it is valid.

5. The system generates a random password using the selected length.

6. The generated password is analyzed to determine its strength.

7. The generated password is added to the current session history.

8. The user can view the passwords stored in the history.

9. After completing an operation, the program returns to the main menu.

10. The program ends when the user chooses the Exit option.
