# SecurePass – Random Password Generator

## Introduction

SecurePass is a Python-based random password generator.
It can generate random passwords and analyze their strength.
The project also keeps a history of generated passwords.

## Features

- Random password generation
- Password strength analysis
- Password history
- Input validation
- Simple menu-based program

## Technologies Used

- Python
- VS Code
- Python Standard Library
